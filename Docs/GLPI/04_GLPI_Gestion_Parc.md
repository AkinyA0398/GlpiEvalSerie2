# GLPI - Gestion du Parc Informatique

## Introduction

La gestion du parc informatique permet d'inventorier, suivre et maintenir tous les actifs de l'entreprise.

---

# Types d'actifs

## Ordinateurs

Informations :

* Nom
* Numéro de série
* Fabricant
* Modèle
* CPU
* RAM
* Disque
* Adresse IP
* Système d'exploitation

## Serveurs

* Serveurs physiques
* Serveurs virtuels
* Hyperviseurs

## Imprimantes

* Adresse IP
* Modèle
* Emplacement

## Moniteurs

* Taille
* Résolution
* Numéro de série

## Équipements réseau

* Routeurs
* Switchs
* Pare-feu
* Bornes Wi-Fi

---

# Cycle de vie d'un équipement

```text
Achat
 ↓
Réception
 ↓
Déploiement
 ↓
Exploitation
 ↓
Maintenance
 ↓
Réforme
```
